Votre assistant STI, dans votre navigateur

Un modèle d'intelligence artificielle libre (Qwen 2.5) tourne directement sur cet ordinateur : aucune donnée n'est envoyée sur Internet, aucun compte ni abonnement. Pour chaque question, il reçoit les fiches de l'annexe officielle qui s'y rapportent, et chaque code qu'il propose est vérifié automatiquement.

Ce navigateur ne peut pas faire tourner le modèle. Il faut Chrome ou Edge récent (version 113 ou plus) sur ordinateur, avec WebGPU activé. Vous pouvez utiliser la recherche rapide, qui fonctionne partout.
Choisir le modèle

Le modèle est téléchargé une seule fois, puis conservé par le navigateur pour les visites suivantes.

Préparation…

L'IA peut se tromper : vérifiez avec les fiches citées sous chaque réponse.
